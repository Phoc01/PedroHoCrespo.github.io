# Atlas Bull

Página de apresentação do Atlas Bull, desenvolvida com HTML, CSS e JavaScript puro, sem dependências ou etapas de build.

Abra `index.html` no navegador ou sirva esta pasta com um servidor estático. Os caminhos de estilos, scripts e imagens são relativos, compatíveis com o GitHub Pages deste repositório.

A página apresenta aplicações possíveis de agentes de IA para empresas. O percurso interativo apresenta missão, agentes, revisão e entrega. O visitante pode selecionar etapas, iniciar e pausar a demonstração. Os serviços abrem seus exemplos correspondentes. São interações locais, sem chamadas a modelos ou dados ao vivo. Não usa a captura interna do Office.

O formulário prepara uma mensagem no WhatsApp ou e-mail; o visitante confirma o envio no serviço escolhido. Não há backend, armazenamento de formulário ou analytics. Os contatos diretos também funcionam sem JavaScript.

Verificação local: telas de 320, 390 e 1440 px, navegação móvel, exemplo interativo, campos obrigatórios, preparação do WhatsApp e carregamento de imagens. Nenhuma mensagem foi enviada durante os testes.

`jsilva-contabilidade/` foi preservada.

Animações respeitam prefers-reduced-motion: com essa preferência, o percurso avança apenas por ação do visitante. Há navegação por teclado nas etapas e fallback de conteúdo/contato sem JavaScript. Nenhuma dependência foi instalada para o refino.
